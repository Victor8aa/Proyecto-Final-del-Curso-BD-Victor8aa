Proyecto Final del Curso – Bases de Datos

Casa de Jade

Creador: Victor (@Victor8aa)

Descripción
Aplicación desarrollada en Java con JavaFX y MySQL para gestionar clientes, administradores, productos, membresías e historial de compras.

Tecnologías
- Java
- JavaFX y FXML
- MySQL
- JDBC
- IntelliJ IDEA

Requisitos
- JDK y JavaFX
- MySQL Server
- Driver JDBC de MySQL

Configuración
1. Clonar o descargar el repositorio.
2. Configurar la conexión a la base de datos `Casa_de_Jade` en `ConexionDB.java`.
3. Ejecutar la clase `Launcher.java`.
